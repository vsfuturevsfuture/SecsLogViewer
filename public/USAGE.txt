SECS 日志解析工具 —— 使用说明（网页版）
========================================

一、怎么打开
  1. 把 index.html 拷到任意位置（桌面也行），双击打开。
     建议用 Chrome 或 Edge；如果双击是用 IE 打开的，右键 →“打开方式” → Chrome / Edge。
  2. 就这一个文件，不用安装任何东西、不用联网，也不需要 Node.js。

二、怎么用
  1. 第 1 栏：把日志文件（如 2026-09-17.txt）拖进去，或点“选择文件…”；
     也可以点“选择文件夹…”直接选整个日期文件夹；点“载入示例数据”可以先试一遍。
  2. 第 2 栏：把名称表拖进去（可以两张一起）：
       ECID.cfg —— 设备常数表（S2F13 / S2F14 这类消息的键用）
       SVID.cfg —— 状态变量表（S1F3 / S1F4 这类消息的键用）
     不放也能用，只是只显示编号、不显示名称。
  3. 第 3 栏选请求 / 应答码（默认 S2F13 → S2F14），点“开始解析”。
  4. 右边看结果：
       明细（键 => 值）  26555 = 1.6，名称是 SDC8_GPPosHom
       横向对比         同一变量在多次采样里的值并排，有变化会标黄
       原文             这一对消息的原始文本
       消息含义         每个 SxFy 是干啥的（如 S16F21 = Process Job Get Space）
       趋势图           选变量画折线，拖拽放大、双击还原，可导出 PNG / CSV
  5. 右上角可以“跳到第 N 对”；导出的 CSV 能直接用 Excel 打开（不会乱码）。

三、注意事项
  · 一定要用 Chrome 或 Edge，IE 打不开这个页面。
  · 解析全在本机内存里做，不会上传任何数据，也不需要连网。
  · 日志里中文显示乱码不用管，工具会自动识别 UTF-8 / GBK。
  · 想给别人用：把这一个 index.html 发给他就行（U 盘、共享盘、微信都可以）。

四、想放到公司内网当网页用（可选）
  把 index.html 放进任意 Web 服务器的站点目录（IIS 的 wwwroot、nginx 的 html 目录），
  访问 http://服务器地址/index.html 即可。这是纯静态页面，不需要后端、不需要数据库。
