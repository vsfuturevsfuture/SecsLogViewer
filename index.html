    解析规则说明
    • 消息头形如 08:06:00.971 S2F13 [H->E, 9018402]：时间 / 消息码 / 方向 / messageID。
    • 配对规则：请求后面紧邻的那条应答，且 messageID 相同，才算一对。
    • 键值规则：请求 <L[n]> 下第 i 项是键（如 <U4[1] 26555>），应答同位置的项是值（如 <F8[1] 1.6>），顺序一一对应。
    • ECID.cfg 列：EC | ID | FORMAT | NAME | UNITs | IONAME | IOTYPE，用 ID 查出名称。
    • 日志行前面的 2026-09-17 00:21:27.0088 [t:36][Debug]Secslog: 前缀不影响解析；无正文的消息记为 <header only>。
    配对： 跳到第
